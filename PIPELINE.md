# SEPO Training Pipeline

Paper: Safe Equilibrium Policy Optimization (SEPO)
Objective: `J(π) = u(π) - λe·e(π) - λc·c(π) - λx·x(π)`
Strategic safety index: `S(π) = u - 3e - 4c - 2x`

## Stage 1 — SFT Warm Start (local Mac, 8GB RAM)

**Goal**: Fine-tune Gemma 3 4B to behaviorally imitate SEPO-optimal strategy traces
(TFT 85.2%, Grim 11.5%, AlwaysDefect 2.0%, GenTFT 0.8%, AlwaysCooperate 0.5%)

**Data**: `sepo_sft_data/` — 6400 train / 1600 valid, chat JSONL (`messages` key)
- Generated by `sft_data_gen.py`
- Actions: `<SILENT>` = cooperate, `<TESTIFY>` = defect

**Run**:
```
bash train_sft.sh
```

**Output**: `adapters/sepo_qlora/` (LoRA adapter weights)

**Memory flags used** (8GB constraint):
- 4-bit quantized base model (`mlx-community/gemma-3-4b-it-4bit`)
- `--grad-checkpoint` — recomputes activations instead of storing
- `--num-layers 8` — LoRA on 8 layers only (default is 16)
- `--max-seq-length 512`
- `--grad-accumulation-steps 4`

## Stage 2 — GRPO with SEPO Objective (cloud)

**Goal**: Equilibrium-aware RL fine-tuning starting from the SFT checkpoint

**Starting point**: fused model from Stage 1b (uploaded to HF Hub)

**GRPO reward function** = SEPO objective:
- Payoff: score from IPD game vs opponent
- Exploitability penalty: counterfactual loss vs adversarial opponents
- Collusion penalty: coordination with collusive partner types
- Externality penalty: domain-specific (welfare shortfall in IPD)

**Opponent pool**: AlwaysCooperate, AlwaysDefect, TitForTat, GenerousTFT, GrimTrigger

**Key files for reward logic**:
- `llm_sepo_optimizer.py` — SEPO objective computation
- `llm_sepo_ipd.py` — LLM vs opponent evaluation
- `sepo_gtbench_ipd.py` — strategy classes and game constants
